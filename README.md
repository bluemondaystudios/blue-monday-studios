# Blue Monday Studios

React + Vite marketing site for Blue Monday Studios.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is generated in `dist/`.

## GitHub Pages

This project is configured with Vite's relative base (`./`), so it can be served from a GitHub Pages project site without changing asset paths.

For a simple deployment:
1. Push the project to GitHub.
2. Run `npm install`.
3. Run `npm run build`.
4. Publish the `dist/` folder through GitHub Pages, or add a GitHub Actions workflow later.

## Stack

- React
- Vite
- Framer Motion
- Lucide React
- CSS
